# 📖 What I Learned Today

## 1. Exploring `/proc`

`/proc` is a virtual filesystem generated by the Linux kernel.

Unlike normal filesystems, nothing inside `/proc` is permanently stored on disk.

Every file is generated dynamically when it is read.

---

## 2. Process Inspection

### Process Status

```bash
cat /proc/<PID>/status
```

Displays:

- Process name
- Process state
- Memory usage
- Thread count
- User IDs
- Capability information

Useful during production troubleshooting.

---

### File Descriptors

```bash
ls /proc/<PID>/fd
```

Displays every open file descriptor.

This includes:

- Files
- Pipes
- Sockets
- Devices

Everything in Linux is represented as a file descriptor.

---

### Virtual Memory

```bash
cat /proc/<PID>/maps
```

Displays the virtual memory layout of the process.

Each mapping includes:

- Virtual address range
- Permissions
- Offset
- Device
- Inode
- Backing file

This is commonly used when debugging memory allocation and shared libraries.

---

### Memory Summary

```bash
pmap -x <PID>
```

Provides a cleaner summary of process memory usage than `/proc/<PID>/maps`.

---

## 3. Resource Limits

Viewed current limits:

```bash
ulimit -n
```

Modified the soft limit:

```bash
ulimit -n 4096
```

Verified:

```bash
cat /proc/$$/limits
```

This demonstrated that shell resource limits are reflected inside `/proc`.

---

## 4. Terminal Multiplexing

Created a session:

```bash
tmux new -s dev
```

Detached:

```
Ctrl-b d
```

Listed sessions:

```bash
tmux list-sessions
```

Reattached:

```bash
tmux attach -t dev
```

`tmux` allows terminal sessions to continue running even after disconnecting from SSH.

---

## 5. Vim Macros

Started recording:

```
qq
```

Stopped recording:

```
q
```

Replay:

```
@q
```

Replay five times:

```
5@q
```

Macros eliminate repetitive editing and improve efficiency.

# ❌ Mistakes I Made Today

| Mistake | Why It Happened | How I Fixed It |
|----------|-----------------|----------------|
| Initially thought `/proc` was stored on disk | It behaves like a normal directory | Learned that it is generated dynamically by the kernel. |
| Confused `VmRSS` and `VmSize` | Both represent memory usage | Learned that RSS is physical memory while virtual size includes mapped address space. |
| Forgot to detach from `tmux` correctly | Closed the terminal instead | Used `Ctrl-b d` to detach without stopping the session. |
| Accidentally overwrote a Vim macro | Recorded into the same register | Learned to choose registers deliberately. |
